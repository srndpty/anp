# anp

学習向けの PDF リーダー。非破壊アノテーションと強力なダークモードを備える。

技術書・数学書・問題集を読むための個人用デスクトップアプリケーション。PDF ファイル
自体は変更せず、学習メタデータは別途 SQLite に保存する。主対象は Windows 11。

## できること

**フェーズ番号での進捗はここには書かない**（すぐ古くなるため）。いま動く
機能は下の一覧が唯一の情報源で、この先の予定は [ロードマップ](#ロードマップ)
にまとめてある。

### 読む

- PDF を開いて**連続スクロール**で読む
- 拡大・縮小、実際の大きさ、**幅に合わせる**、**ページ全体**
- Ctrl + ホイールで、カーソル位置を動かさずに拡大・縮小
- ページ番号を指定しての移動、前後のページへの移動
- **目次**（表示メニュー → 目次）から見出しへ移動する。PDF に目次が
  無ければ空のまま
- **本文の検索**（移動メニュー → 検索、`Ctrl+F`）。一致箇所を強調し、
  前後の一致へ移動できる
- **最近使ったファイル**（ファイルメニュー）から開き直す
- 前回終了時に読んでいた PDF と**読書位置**を、次回の起動で復元する
- 全画面表示

### 見た目

- **ページの色**（表示メニュー → ページの色）をオリジナル / 反転 /
  スマートダークから選ぶ。色が変わるのは PDF のページ画像だけで、
  キャンバス・ツールバー・メニューは元のまま
- **キャンバスの色**（表示メニュー → キャンバス）を黒 / ダークグレー / 白から選ぶ
- **UI テーマ**（表示メニュー → UI テーマ）をシステム / ライト / ダークから選ぶ。
  メニューやツールバーの配色だけが変わり、PDF のページ画像には影響しない
- ウィンドウの位置・サイズ、倍率とその決め方、外観の設定を次回起動時に復元
- **キーボードショートカットの変更**（設定メニュー → ショートカット）

ページの色・キャンバス・UI テーマは**互いに独立した3つの軸**で、どの組み合わせでも
選べる。片方を変えたからといってもう片方が追随することはない。

高 DPI（125% / 150%）のスケーリングに合わせた解像度でレンダリングする。

### 学習マーク

間違えた問題の位置を記録する非破壊アノテーション。**PDF ファイルは
書き換えず**、`%LOCALAPPDATA%\anp\anp.sqlite3` に保存する。

- ページの上を **Ctrl + 左クリック**でマークを作る（間違えた回数は 1 から）
- 既存のマーク（バッジ）を **Ctrl + 左クリック**で間違えた回数を1増やす
- 右クリックメニューから、回数を増やす / メモを編集する / 削除する
- **一覧**（表示メニュー → 学習マーク）から、回数で絞り込み、行を選べば
  その位置まで移動する

マークは「PDF のパス＋内容」で結び付ける。**同じパスの PDF を別の内容へ
差し替えると、以前のマークは表示されない**（消えるわけではなく、元の
PDF に戻せばまた出てくる）。逆に、PDF を移動・リネームした場合は
以前のマークと結び付かない。

### スマートダークについて

**スマートダーク（Smart Dark v1）は、色相と彩度を保ったまま明度だけを反転する。**
HSL で言えば `L` だけを `1 - L` にする変換で、白地に黒文字のページは反転と同じように
暗くなる一方、図表・数式・シンタックスハイライトの色は補色に変わらない。

- 白黒のページ（無彩色）では、結果は単純な反転と完全に一致する
- 赤は赤、青は青のまま。単純な反転では赤が水色になってしまう

**写真領域を検出して元の明るさを保つ処理はまだ行わない。** 写真も色相は保たれるが
明暗は反転するため、写真の多い PDF では不自然に見えることがある。その場合は
オリジナルに戻して読むこと。

## ロードマップ

まだできないこと。

- 写真領域を判別するスマートダーク（いまは写真も明暗が反転する）
- パスワード付き PDF を開く
- 任意の色を指定できるキャンバス
- PDF を移動・リネームしても学習マークを追跡する

作らないもの（PDF のテキスト・画像編集、ページの挿入や削除、OCR、
電子署名、クラウド同期、手書き、AI 機能など）は
[AGENTS.md の非目標](AGENTS.md#非目標)にまとめてある。

## キーボードショートカット

既定値は次のとおり。**設定メニュー → ショートカット**から変更できる。

| キー | 動作 |
|---|---|
| `Ctrl+O` | PDF を開く |
| `Ctrl+Q` | 終了 |
| `Ctrl++` / `Ctrl+=` | 拡大 |
| `Ctrl+-` | 縮小 |
| `Ctrl+0` | 実際の大きさ（100%） |
| `Ctrl+PgUp` / `Ctrl+PgDown` | 前 / 次のページ |
| `Ctrl+F` | 検索 |
| `F3` / `Shift+F3` | 次 / 前の一致 |
| `F11` | 全画面表示の切り替え |
| `Esc` | 全画面表示を抜ける |
| `Ctrl` + 左クリック | 学習マークを作る / 間違えた回数を増やす |
| `Ctrl` + ホイール | カーソル位置を中心に拡大・縮小 |

「幅に合わせる」「ページ全体」はツールバーと表示メニューから、
「ページの色」「キャンバス」「UI テーマ」「目次」「学習マーク」は
表示メニューから選ぶ。`PageUp` / `PageDown` は通常のスクロール操作の
ままにしてある。

## 必要なもの

- Python 3.12 以上
- [uv](https://docs.astral.sh/uv/)

## セットアップ

```bash
uv sync --all-groups
uv run pre-commit install
```

## 実行

```bash
uv run anp
```

## 開発

```bash
uv run pytest --cov=anp   # テスト
uv run ruff check .       # lint
uv run ruff format .      # 整形
uv run mypy               # 型チェック
```

開発規約は [AGENTS.md](AGENTS.md) を参照。

## データの保存場所

| 種類 | 場所 |
|---|---|
| ログ | `%LOCALAPPDATA%\anp\logs\anp.log` |
| データベース | `%LOCALAPPDATA%\anp\anp.sqlite3` |
| 設定 | レジストリ `HKEY_CURRENT_USER\Software\anp\anp` |
